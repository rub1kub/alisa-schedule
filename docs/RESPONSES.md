# Ответы Алисы

Все реплики и подписи кнопок лежат в `data/responses.json`. Логика диалога выбирает шаблон и подставляет данные. Кабинеты остаются в модели расписания, но в ответ не попадают.

## Что слышит студент

При первом запуске: «Кэпик подскажет расписание колледжа. Назовите группу или фамилию преподавателя». Кэпик запоминает выбор. При следующем запуске предлагает спросить «что завтра» или назвать день недели. Если вопрос прозвучал до выбора расписания, после выбора ответит на него.

Способ запуска определяет поведение по умолчанию. «Алиса, запусти навык Кэпик тест» открывает разговор: можно сказать «завтра», затем «предметы» или «а на второй?». «Спасибо» или «хватит» завершает разговор. «Алиса, спроси у Кэпика тест, что завтра» даёт ответ и закрывает навык без прощания. Если сначала нужно выбрать группу или преподавателя, уточнить дату или дочитать длинное расписание, выход происходит после завершения этого запроса.

В режиме автовыхода ответы «пар нет», «расписание не опубликовано», «попробуйте позже» и подтверждения настроек тоже завершают разговор. Справка завершает отдельный запрос, но сохраняет разговор при выборе группы, преподавателя, дня, номера пары или продолжении длинного ответа. При отдельном запуске ответы оставляют навык открытым. Группа или преподаватель, формат и явно выбранный режим выхода сохраняются для следующего запуска; автоматический выбор режима относится только к текущей сессии.

По умолчанию первый курс слышит предметы, второй–четвёртый — фамилии. Курс берётся после последнего дефиса в обозначении группы. Для нестандартного кода задайте курс явно в `college.json`:

```json
"group_courses": {"103-Д9-3ИНС": 3}
```

Инициалы из поля преподавателя удаляются. Если преподаватель не указан, звучит предмет. Предупреждения о сохранённой копии, примере расписания, замене и примечания к дню сохраняются при любом режиме.

| Команда | Результат |
| --- | --- |
| «Называй предметы» | Сохранить режим предметов |
| «Называй преподавателей» или «называй фамилии» | Сохранить режим фамилий |
| «Называй предметы и преподавателей» | Сохранить режим обоих полей |
| «Предметы и преподаватели», «фамилии» | Уточнить только этот ответ |
| «Выбирай по курсу» | Вернуться к правилу курса |
| «Какие предметы завтра?» | Предметы только в этом ответе |
| «Какой предмет на второй паре завтра?» | Предмет второго номера пары |
| «Предметы» или «а какие предметы?» | Разовое уточнение без смены постоянного режима |
| «Кто на второй паре завтра?» | Фамилия для второго номера пары |
| «Кто ведёт первую пару?» | Фамилия для первой пары своей группы |
| «Расписание группы 104 завтра» | Разовый запрос другой группы |
| «Расписание у Примеровой» | Пары преподавателя на сегодня |
| «Сколько пар у Примеровой завтра?» | Количество занятых номеров пар |
| «Первая», «последняя», «сколько» | Короткий вопрос о выбранном дне |
| «Ко скольки завтра?», «до скольки завтра?» | Время начала или конца занятий |
| «Оставайся в навыке» | Сохранить отключённый автовыход |
| «Выходи после ответа» | Сохранить включённый автовыход |

Постоянный выбор сохраняется вместе с группой в хранилище Яндекса. «Забудь группу» очищает группу, сохраняя формат ответа. Гостевое приложение и авторизованный пользователь имеют отдельные настройки.

## Разовые уточнения

Один преподаватель может вести разные предметы. Чтобы услышать предметы для всего дня, спросите «какие предметы завтра». Для отдельной пары — «какой предмет на второй паре завтра». Ответ сохраняет все подгруппы этого номера. Если такого номера нет в опубликованном расписании, навык скажет «2-й пары нет»; отсутствие публикации остаётся отдельным ответом.

Пока навык открыт, «а предметы» сохраняет день и адресата последнего ответа. После первой пары или конкретного номера «а какой предмет» уточняет именно эту пару. После расписания дня — весь день. «А на второй» выбирает второй номер. Явно названный новый день имеет приоритет.

После автовыхода нужно заново назвать навык и день: «Алиса, спроси у Кэпика, какой предмет на второй паре завтра». Для тестовой версии — «у Кэпика тест». Контекст завершённого разговора не переносится в новый; выбранная группа и постоянные настройки сохраняются.

«Первая пара» означает первое занятие дня, даже если оно стоит вторым номером. «На первой паре» означает именно номер 1. Номер распознаётся цифрами и словами, от 1 до 12; непонятный номер требует уточнения. Время конкретного номера подчиняется `schedule_time`.

Предметы можно запросить и для преподавателя: «какие предметы у Примеровой завтра». В этом ответе звучат группы и предметы, даже если `teacher_lesson_label` настроен только на группы. Если в источнике нет предмета, ответ — «предмет не указан». Фамилия в примере вымышлена.

## Группа и преподаватель

«Моя группа 104», «смени группу на 104» и выбор группы при первом знакомстве сохраняют группу. Вопрос о расписании другой группы её не меняет. В начале такого ответа группа звучит один раз, чтобы можно было заметить ошибку распознавания.

Для преподавателя звучит фамилия один раз, затем номера пар и группы. Кабинеты и инициалы не звучат. Две группы в одном номере пары считаются одной парой; запрос первой пары сохраняет обе группы. `teacher_lesson_label: "both"` добавляет предметы. Правило курса относится к расписанию студенческой группы.

Уточнение фамилии или даты сохраняет исходный вопрос — например, «сколько пар завтра». Если полного расписания нет, навык говорит об этом. Он не выдаёт отсутствие публикации за свободный день.

## Настройки владельца

Поле `options`:

| Ключ | По умолчанию | Значение |
| --- | --- | --- |
| `auto_exit` | `true` | Завершать запрос с вопросом при запуске после полного ответа; `false` всегда оставляет навык открытым |
| `interactive_launch` | `true` | При отдельном запуске без вопроса слушать уточнения; `false` применяет `auto_exit` и к такому запуску |
| `teacher_lesson_label` | `group` | `group`: номера пар и группы преподавателя; `both`: добавить предметы |
| `lesson_label` | `auto` | `auto`, `subject`, `teacher` или `both` |
| `course_labels` | `1: subject`, `2–4: teacher` | Режим для каждого курса |
| `show_group` | `false` | Повторять группу перед расписанием |
| `schedule_time` | `none` | `none`, `start` или `range` для расписания дня |
| `first_time` | `start` | Время первой или последней фактической пары: `none`, `start` или `range` |
| `date_format` | `none` | `none`: без даты; `short`: «16 сентября»; `full`: с годом и днём недели |
| `page_chars` | `700` | Длина части ответа, 300–1024 символа |

Личная команда автовыхода имеет приоритет над обеими настройками: «выходи после ответа» закрывает и отдельно запущенный навык, «оставайся в навыке» оставляет открытым и запрос одной фразой. Без личной настройки режим определяется первым запросом сессии. Открытый разговор не записывает предпочтение автовыхода при выборе группы или формата. «Забудь группу» сохраняет формат, личную настройку выхода и режим текущего разговора. Следующая короткая команда про первую пару или количество относится к только что названной группе или преподавателю.

Приоритет формата: конкретный вопрос → сохранённый выбор студента → настройка владельца → правило курса. При неизвестном курсе или отсутствии правила используются предметы.

«У 104» и «104 завтра» запрашивают чужую группу разово. Пока разговор открыт, смена дня сохраняет адресата; «а у 104» и «а у Примеровой» сохраняют день. «А моя» или «а у меня» возвращает сохранённое расписание. После автовыхода день и адресата нужно назвать заново.

Явный вопрос о времени использует шаблоны `day_start`, `day_finish` и `time_missing`, независимо от `schedule_time`. Если у подгрупп разное время, звучит самое раннее начало или самое позднее окончание. При пропущенном времени оно не угадывается.

В `texts` можно менять формулировки. `welcome_group` — первый запуск без группы, `welcome` — запуск с выбранной группой, `ask_group` — уточнение группы в текущем запросе. В обоих приветствиях сохраняйте назначение навыка и пример следующей команды. Например:

```json
"welcome": "Подскажу расписание колледжа. Спросите: что завтра?",
"day_count": "{count}.",
"lesson": "{number}-я — {label}"
```

`label` уже содержит предмет, фамилию или оба поля. Список ключей и разрешённых подстановок задан в `app/responses.py`. Ключи и подстановки нужно сохранять. Обращения к атрибутам, индексы, преобразования и форматирующие выражения не поддерживаются. Пустой, неизвестный или слишком длинный шаблон не проходит проверку.

## Применение

Локально:

```bash
.venv/bin/python -m scripts.validate_data
```

На сервере после редактирования файла:

```bash
cd /opt/alisa-schedule
docker compose run --rm --no-deps skill python -m scripts.validate_data
docker compose restart skill
```

Перезапускайте сервис только после успешной проверки. Пересборка образа для текстов не требуется: каталог `data` подключён к контейнеру. Другой путь задаётся переменной `RESPONSES_FILE`.

«Что ты умеешь» вызывает `texts.capabilities`: краткое описание возможностей. «Помощь» вызывает `texts.help`: конкретные команды и способ выхода. Эти ответы должны различаться; одинаковые тексты не проходят проверку. Обе команды сохраняют выбранный день, адресата и ожидаемое уточнение.

В текстах используйте привычные студенту слова. Один ответ должен решать один вопрос. Не убирайте различие между «пар нет», «расписание не опубликовано» и «источник недоступен».


## Сохранённое расписание

В постоянном состоянии хранится один адресат: `group_id` или `teacher_id`. `teacher_id` — точный идентификатор из каталога преподавателей; фамилия и её произношения служат для поиска. Старые состояния с одним `group_id` читаются без миграции. Признак преподавателя выбирает расписание и не подтверждает личность или права доступа.

Авторизованный пользователь получает изменения через `user_state_update`, гость — через `application_state`. При переходе к группе прежний `teacher_id` удаляется; при переходе к преподавателю очищается `group_id`. Формат ответа и настройка выхода сохраняются. Если полный идентификатор дублируется в постоянном состоянии, он может быть опущен в состоянии сессии ради лимита 1024 байта.

`profile_choice` существует только в текущем разговоре. Пока новый выбор не найден однозначно, прежнее расписание остаётся сохранённым. Дата, номер пары и формат исходного вопроса переживают уточнение фамилии, справку и необязательное «я преподаватель». Разовый запрос с явно названной группой или преподавателем ничего не записывает, в том числе при первом запуске.

Реплики `ask_profile`, `teacher_saved`, `my_teacher`, `no_profile` и кнопка `button_teacher` настраиваются в `responses.json`. Код и этот файл с новыми ключами нужно обновлять и откатывать вместе.
