# Проверка студенческих запросов — 16 сентября 2026

Три независимых агента проверяли навык в разных ролях. Первый говорил коротко и разговорно, второй задавал подробные вопросы, третий менял тему и уточнял предыдущий ответ. В первом проходе разобрано 152 реплики и шага; часть сценариев пересекалась. Два агента повторили проверку после исправлений. Код менял только основной агент.

Проверки выполнялись локально на вымышленных расписаниях. Реальные настройки пользователей не изменялись. Контекст уточнений проверялся с отключённым автовыходом. Завершённая сессия не передаёт следующую обычную реплику в навык.

## Найденные и исправленные ошибки

| Запрос или разговор | Проверяемое поведение |
| --- | --- |
| «У 104», «104 завтра», «пары 104 завтра» | Разовый запрос указанной группы; своя группа сохраняется |
| «Что завтра» → «первая», «а первая», «а сколько» | Короткий ответ про завтра |
| «Что завтра» → «а у 104» | Другая группа, прежний день |
| «Группа 104 завтра» → «а в пятницу» | Прежняя группа, новый день |
| «Что завтра» → «а у Примеровой» | Преподаватель, прежний день |
| Расписание преподавателя → «а моя», «а у меня» | Возврат к своей группе |
| Предмет второй пары → «а преподаватель», «а кто» | Фамилия именно для второй пары |
| «Какой преподаватель на второй паре завтра» | Ответ о паре; фамилию вводить не требуется |
| «Предметы», «фамилии», «предметы и преподаватели» | Разовый формат без записи настроек |
| «Без фамилий», «не надо фамилий, только предметы» | Только предметы |
| «Без предметов» | Фамилии; при отсутствии преподавателя действует обычный запасной вариант |
| «Пятница 16 сентября» при несовпадении дат | Уточнение дня |
| «16.09 и 17.09», «16 и 17 сентября» | Уточнение одного дня |
| «В среду 16 сентября завтра» при совпадении | Один выбранный день |
| «Первые две пары», «на второй или третьей» | Уточнение одного номера пары |
| «Завтра две пары», «сколько пар — две или три» | Количество не превращается в номер пары |
| «На 13-й паре» → «вторая» | Уточнение номера с сохранением группы и дня |
| «Последняя», «предмет на последней паре» | Последняя фактическая пара |
| «Ко скольки», «до скольки», «во сколько вторая пара» | Время из данных; при отсутствии — явный ответ об этом |
| «В пт», «чё по парам», «расписание пожалуйста на завтра» | Обычный запрос расписания |
| «Группы 103 и 999», известный и неизвестный преподаватель | Уточнение адресата, без потери неизвестной части |
| Группа и преподаватель в одном запросе → «104» | Разовая группа на исходный день; личная группа сохраняется |
| Фамилия с инициалами «И. Б.» / «И Б» | Инициал не принимается за союз «и» |
| Неверная дата → выбор группы или фамилии → день | Неверная дата не подменяется сегодняшней |

Регрессионные тесты находятся в `tests/test_student_queries.py`; прежние проверки диалога, формата, преподавателей и обоих ID также сохраняются.

## Границы

- Один запрос относится к одному дню и одному адресату. Для нескольких номеров пар навык просит выбрать один; весь день можно запросить словом «расписание».
- Подгруппы учитываются вместе. Личная подгруппа не выбирается.
- Нет опубликованного расписания, свободный день и недоступный источник остаются разными ответами.
- Список фраз покрывает проверенные разговоры, но не гарантирует понимание любого произвольного текста.
- Локальные тесты и HTTPS не проверяют распознавание микрофоном Станции и активацию навыка Яндексом.

## Короткая проверка на Станции

Для тестовой версии: «Алиса, скажи Кэпик тест, что завтра». Затем отдельным обращением: «Алиса, скажи Кэпик тест, какой предмет на второй паре завтра». Публичная версия использует те же команды с именем «Кэпик» после публикации.

Для диалога с уточнениями сначала: «Алиса, скажи Кэпик тест, оставайся в навыке». Затем «что завтра» → «а первая» → «а предмет» → «а у 104» → «а моя». Вернуть обычное поведение: «выходи после ответа».
