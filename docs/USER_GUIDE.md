# Кэпик: настройка и команды

Инструкция для публичного навыка «Кэпик». Его повторно отправили на модерацию; публикация пока не подтверждена. Примеры публичного запуска предназначены для использования после публикации. Приватный «Кэпик тест» доступен аккаунту разработчика, его настройки сохраняются отдельно.

## 1. Выберите свою группу

Скажите:

> Алиса, запусти навык Кэпик.

На вопрос о группе назовите **свой** номер. Например, «сто три» — только для студентов группы 103. Если номер неоднозначен, назовите полное обозначение группы.

Группа запоминается, выбирать её при каждом запуске не нужно. Проверить выбор можно командой «моя группа». Для смены скажите «забудь группу», затем назовите новую по запросу навыка. На общей Станции не рассчитывайте на автоматический выбор группы по голосу каждого члена семьи: при необходимости называйте группу прямо в вопросе.

## 2. Получить ответ одной фразой

> Алиса, спроси у Кэпика, что завтра.

Навык прочитает расписание и по умолчанию закроется. Дальше можно обращаться к обычной Алисе. Произносите **«у Кэпика»**, со склонением.

Другие примеры:

- «Алиса, спроси у Кэпика, что сегодня».
- «Алиса, спроси у Кэпика, расписание на пятницу».
- «Алиса, спроси у Кэпика, какая первая пара завтра».
- «Алиса, спроси у Кэпика, сколько пар завтра».
- «Алиса, спроси у Кэпика, какие предметы завтра».
- «Алиса, спроси у Кэпика, кто на второй паре завтра».
- «Алиса, спроси у Кэпика, ко скольки завтра».

Если группа ещё не выбрана, навык сначала спросит её и затем вернётся к вопросу.

## 3. Поговорить и уточнить

Для нескольких вопросов сначала запустите навык отдельно:

> — Алиса, запусти навык Кэпик.
> — Завтра.
> — А какие предметы?
> — А на второй?
> — Спасибо.

В таком разговоре выбранный день сохраняется. «Спасибо» или «хватит» закрывает навык. Если навык уже закрылся, уточнение нужно снова адресовать ему: «Алиса, спроси у Кэпика, какие предметы завтра».

## 4. Настроить ответы

Произнесите команду внутри навыка:

| Команда | Что изменится |
| --- | --- |
| «Называй предметы» | В расписании будут названия предметов |
| «Называй фамилии» | Будут фамилии преподавателей без инициалов |
| «Называй предметы и преподавателей» | Будут оба поля |
| «Выбирай по курсу» | Первый курс — предметы, второй–четвёртый — фамилии |
| «Оставайся в навыке» | После ответа можно будет продолжать разговор |
| «Выходи после ответа» | После завершённого ответа навык будет закрываться |

Эти настройки сохраняются. Настройка выхода имеет приоритет над способом запуска: например, после «выходи после ответа» даже отдельно запущенный навык закроется после расписания.

«Какие предметы завтра?» меняет только конкретный ответ. «Называй предметы» меняет постоянную настройку. Кабинеты не озвучиваются. Если преподаватель не указан, вместо фамилии звучит предмет.

## 5. Другая группа или преподаватель

В открытом навыке можно спросить:

- «Расписание группы 104 завтра» — подставьте нужную группу.
- «Сколько пар у Евтушенко завтра?» — подставьте фамилию преподавателя.
- «А у меня?» — вернуться к своей группе в текущем разговоре.

Разовый запрос другой группы не заменяет сохранённую свою группу. При нескольких совпадениях навык уточнит выбор. Если расписание не опубликовано, он сообщит об этом: это не означает, что пар нет.

## 6. Короткая команда через «Дом с Алисой»

Можно настроить сценарий, который передаёт навыку полный запрос за вас. Например, говорить **«Алиса, что на завтра»** вместо длинной фразы с названием навыка.

Сначала выберите группу в самом навыке и убедитесь, что обычная команда «Алиса, спроси у Кэпика, что завтра» работает на вашей Станции.

1. Откройте **Дом с Алисой → «+» → Сценарий**.
2. Назовите сценарий, например **«Пары на завтра»**. Выберите дом или комнату своей Станции.
3. В разделе **«Если» → «Добавить условие» → «Фраза»** введите **«что на завтра»** — без слова «Алиса».
4. В разделе **«Тогда» → «Добавить действие»** выберите свою Станцию и действие **«Ответить на вопрос или выполнить команду»**. Название пункта может отличаться в версии приложения.
5. Введите команду **«Спроси у Кэпика, что завтра»**.
6. Сохраните сценарий. Проверьте кнопкой запуска, затем голосом: **«Алиса, что на завтра»**.

Нужно именно выполнение команды. Действие «Прочитать текст вслух» просто произнесёт записанную фразу и не запросит расписание.

Настройка голосового условия описана в [справке Яндекса](https://alice.yandex.ru/support/ru/smart-home/scenarios/voice). Действие «Ответить на вопрос или выполнить команду» также упоминается в [ответах разработчика приложения «Дом с Алисой»](https://apps.apple.com/ai/app/дом-с-алисой/id1582810683). Запуск именно Кэпика через такой сценарий пока не проверен на физической Станции: после публикации нужно проверить его на своём устройстве. Если действие недоступно или сценарий не передаёт запрос, используйте обычную фразу запуска.

### Ещё примеры сценариев

Для каждого вопроса задайте свою фразу и соответствующую команду:

| Вы говорите | Команда в действии сценария |
| --- | --- |
| «Алиса, что на завтра» | Спроси у Кэпика, что завтра |
| «Алиса, предметы на завтра» | Спроси у Кэпика, какие предметы завтра |
| «Алиса, сколько завтра пар» | Спроси у Кэпика, сколько пар завтра |
| «Алиса, ко скольки в колледж» | Спроси у Кэпика, ко скольки сегодня |

Сценарий хранит готовую команду, а не расписание: при каждом успешном запуске навык запрашивает данные заново. «Сегодня» и «завтра» определяются по московскому времени.

Без настроенного сценария фраза «Алиса, что на завтра» не адресована Кэпику и может вызвать обычный ответ Алисы. Если общая фраза распознаётся неоднозначно, выберите более явную: «мои пары на завтра». Если навык остаётся открытым после сценария, проверьте, не включали ли вы «оставайся в навыке».
