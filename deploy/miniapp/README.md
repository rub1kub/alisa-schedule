# Главная страница существующего мини-приложения

Интеграция разрешена владельцем 18 сентября 2026. Без initData показывается лендинг, с initData — прежний интерфейс. Это выбор экрана, а не проверка авторизации: сервер по-прежнему проверяет подпись Telegram.

Подготовка из резервной копии исходного шаблона:

```sh
python scripts/prepare_root_landing.py /path/to/original-index.html artifacts/root-landing/generated
```

Скопировать `index.html` и `kepik_landing.html` в `/var/www/kkepik.ru/templates/`, `kepik-entry.js` — в `/var/www/kkepik.ru/static/js/`. Перед заменой проверить хеш исходного шаблона и сделать резервную копию. Генератор отказывается повторно оборачивать уже изменённый шаблон. При изменении JS повысить его параметр `v` в генераторе: сервер отдаёт статические файлы с длительным кэшем. После обновления шаблонов перезагрузить только WSGI-приложение, изменив время `app.wsgi`; его содержимое не менять.

Исходный лендинг находится в `app/static/about.html`. После изменения его дизайна нужно заново сформировать `kepik_landing.html`, чтобы главная и `/about` совпадали. Скрипты мини-приложения сохранены в исходном порядке; контейнер имеет `display: contents` в Telegram и не меняет сетку интерфейса.

Резервная копия на сервере: `/opt/alisa-schedule/root-landing-backup-20260918/index.html`. Для отката достаточно восстановить её в `templates/index.html` и обновить время `app.wsgi`; добавленные файлы без ссылки из шаблона не используются.
